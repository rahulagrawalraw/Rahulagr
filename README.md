# Rahul Agrawal — RAW Premium Portfolio V2

A premium, editorial-style one-page teacher/EdTech portfolio for GitHub Pages.

### Design
- RAW / Rahul Agrawal personal branding
- Dark editorial hero + light content sections
- Animated network/coding background
- Scroll progress indicator
- Responsive mobile navigation
- Reveal-on-scroll animation
- Skills/expertise and selected-work sections
- Teaching philosophy and journey timeline
- GitHub Pages friendly — no build system required

### Before publishing
1. Add your professional photo.
2. Add `assets/Rahul-Agrawal-CV.pdf`.
3. Replace/update project details and social links as required.
4. Upload the files to a GitHub repository.
5. Enable **Settings → Pages → Deploy from branch → main → / (root)**.
