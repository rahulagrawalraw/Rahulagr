Structured Pedagogical Framework

A scaffolded, 3-phase curriculum designed to move learners from visual intuition to production syntax.

01

Visual Logic & Tracing

Eliminates syntax intimidation through block-based frameworks (Scratch, PictoBlocks). Introduces state management, loops, and modular algorithmic flowcharts.

02

Structured Python & Data

Middle to Secondary Grades

Translates logic models into clean, PEP-8 compliant Python. Emphasizes lists, dictionaries, conditionals, file handling, and terminal problem-solving.

03

Web Development & AI Foundations

Senior Secondary & Capstone

Hands-on HTML5/CSS3 layout design, basic DOM scripting, machine learning concepts, and critical digital citizenship and safety principles.
